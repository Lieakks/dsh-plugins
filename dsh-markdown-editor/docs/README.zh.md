# @lieakks/dsh-markdown-editor

*在右侧边栏的 Markdown 预览里直接编辑：所见即所得（Vditor IR）、分栏实时预览、源码与预览四种模式，保存回同一个工作区文件。*

[English](../README.md) | 中文

## 概要

侧边栏的 Markdown 预览就是编辑器，提供四种模式：

- **所见即所得**——内置 Vditor 4.0.1 的 IR（即时渲染）模式，接近 Typora：直接在渲染结果上改，输入 Markdown 语法时即时成形。
- **分栏**——左源码、右实时渲染（本插件自己的渲染器），输入即更新。
- **源码**——只看 Markdown 原文。
- **预览**——只看渲染结果。

Ctrl/Cmd+S（或「保存」）写回磁盘上的同一个文件；磁盘文件被改动时按钮变成「覆盖保存」；检测到外部修改时提供「重新加载」。前导 YAML frontmatter 在所见即所得模式下会被拆出并原样拼回，不会被编辑器改写。相对路径或本地路径的图片，与分栏视图一样通过源文件所在目录经鉴权的 `api/file` 路由显示。

工作区文件 Remote（`@deepseek-ai/dsh-api-workspace-files`）不提供写入操作，因此写入通道由 Host 半的两条鉴权路由承担。Vditor 的运行时资源也由 Host 半的静态路由提供（`/markdown-inline-editor/vditor/...`），**完全离线，不访问任何 CDN**。

## 出现位置

- **预览本身**——本插件注册的 Markdown 预览实现（`extension` 频段，默认优先于内置 `builtin` 渲染器）；预览头部的查看器下拉里仍可切回内置只读渲染。
- **工具栏**——`所见即所得 / 分栏 / 源码 / 预览` 四个模式、未保存标记、**保存**（冲突后变**覆盖保存**）；模式选择会记住。
- **提示行**——保存失败、外部修改（带「重新加载」）、所见即所得引擎加载失败（带「切回分栏」）。

面板宽度小于约 620px 时，分栏自动改为上下堆叠。

## 用法

1. 在侧边栏文件树或文件链接中打开一个 Markdown 文件。
2. 默认进入上次使用的模式；点「所见即所得」即可在渲染结果上直接编辑（首次加载约 3.7MB 的 Lute 解析器，走本机路由）。
3. Ctrl/Cmd+S 保存；若磁盘文件已被改动，按钮变「覆盖保存」，再按才写入。
4. 想精确控制格式时切到「源码」或「分栏」；只想阅读时切到「预览」。

## 构建与运行

- `src/client.js` 是浏览器半源码；`build/build.mjs` 用 esbuild 把它与 Vditor 主脚本、样式一起打包成 `client.js`（约 372 KB）。
- 依赖装在 `build/`：`cd build && npm install && node build.mjs`。
- Vditor 按需加载的资源（Lute、i18n、图标、highlight.js 及各图表/公式引擎）复制在 `vendor/vditor/js`，由 Host 路由按扩展名白名单提供，路径不能越出该目录。
- 许可证：Vditor 4.0.1 为 MIT；其 runtime 内含的第三方库见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。

## Host 路由的校验

两条编辑路由都先向组合的 `connection` 服务请求拒绝判定（Host/Origin 围栏与浏览器鉴权），然后要求：

- 是本 Host 中正在运行的会话（`sessions`）；
- 绝对路径经真实路径解析后位于该会话的有效工作目录内（`workingDirectory`，取不到时回退到会话头部的项目目录）；
- 是已存在的普通 Markdown 文件，且本身不是符号链接；
- JSON 请求体不超过 8 MiB，文本不超过 2 MiB 且为合法 UTF-8。

不会新建任何文件：不存在的文件会被拒绝。静态路由只读取 `vendor/vditor` 下的文件，扩展名白名单（js/css/json/map/svg/png/gif/jpg/jpeg/webp/woff/woff2/ttf），拒绝 `..`、反斜杠和编码后的路径穿越。

## 已知限制

- **所见即所得会规范化 Markdown**——Vditor 保存时用它自己的序列化结果覆盖原文：列表符号、表格对齐、部分空白可能变化；frontmatter 已单独拆出保留，但不保证逐字节不变。需要精确格式时用「源码」。
- **首次进入所见即所得需加载 Lute**（约 3.7MB，本机 HTTP，通常很快）。
- **只支持 Markdown、只改已存在的文件**——不新建、不重命名、不删除，文本上限 2 MiB。
- **只支持运行中的会话**——本 Host 中未运行的会话能看不能存。
- **不做合并**——磁盘上的变化只提示不合并，第二次保存即覆盖。
- **草稿不跨页面**——未保存文本在页面生命周期内按文件保留（切标签、面板、模式再回来会恢复），刷新页面则丢失。
