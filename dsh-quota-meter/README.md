# @lieakks/dsh-quota-meter

在输入框下方显示**本会话已用额度**。

## 功能

- 输入框下方常驻 `本会话已用额度`，任务运行时自动刷新，任务结束后补读一次
- 没有会话在跑时不无谓轮询；页面重新可见时立即补一次读数
- 悬停可看本会话的起始基准与统计起始时间
- 确实无法归属的余额下降单独累计为「未能归属到会话」，只在悬停提示里显示，用来和账号实际变化对账

## 统计口径

账号余额是所有会话共用的，所以按「**两次读数之间谁在跑**」来分摊：

- 两次读数之间余额下降多少，就记在期间运行过的会话上；多个会话同时运行按会话均分
- 充值、退款导致的余额上升不计入消耗，也不会清零已有数字
- **子智能体**：它本身是独立会话，但消耗一律归到**派发它的会话**，不为看不见的子会话立账
- **迟到结算**：余额在运行结束之后才扣款时，5 分钟内到达的这笔补记给最近运行过的会话
- **长时间未观测**：超过 5 分钟没有读数（页面关着），期间变化不猜归属，以当前余额作为新基准

这是**估算而非账单**：用来看趋势和相对消耗，不要拿它对账。

## 安装

```
plugin_manager install_bundle target=@lieakks/dsh-quota-meter
```

或从源码仓库安装：

```
plugin_manager install_bundle target=<本仓库路径>/dsh-quota-meter
```

## 与其它插件的关系

装了 [`@lieakks/dsh-plugin-input-polish`](https://www.npmjs.com/package/@lieakks/dsh-plugin-input-polish) 时，润色按钮调用模型的消耗会被记到**发起润色的那个会话**上，其它会话不受影响。额度插件只在宿主插件清单确认该插件存在时才注册这个监听。

## 说明

只用浏览器本地存储记录账本，不上传数据。兼容 DSH `>=0.2.2-0 <0.3.0`。
