# @lieakks/dsh-skins

DeepSeek Harness Web 界面的**整站皮肤**：换配色、换壁纸、治背景图上的灰字。

## 功能

设置 → 皮肤，分三块：

- **配色皮肤**：默认 / 极光青 / 暖沙 / 森林 / 霓虹紫，每套都含浅色与深色两版，跟随「通用设置 → 外观」
- **背景图**：选本地图片或粘贴图片链接
  - 本地图片自动压到最长边 2560，保留透明通道（存 IndexedDB，不上传）
  - 图片链接按原图加载，不占本机存储
  - 可调 `暗化`（蒙层深浅）、`面板通透度`（卡片/侧栏通透程度）、`遮罩浓度`（打开设置时背景雾化）
- **文字**：`面板明暗` 决定玻璃底是深是浅，`文字配色` 可选自动 / 高对比 / 柔和 / 自定义取色，专治背景图上的灰字看不清

## 安装

```
plugin_manager install_bundle target=@lieakks/dsh-skins
```

或从源码仓库安装：

```
plugin_manager install_bundle target=<本仓库路径>/dsh-skins
```

## 已知限制

- 背景图靠 `--dsw-alias-bg-base` 铺画布，个别自带不透明底色的区域不会透出图片
- 远程图片若不允许跨域读取，无法测量亮度，「自动」文字配色退化为跟随外观明暗
- 窄窗口（<768px）下设置面板铺满视口，不参与浮层雾化
- 皮肤、壁纸、文字配色按浏览器保存，换浏览器或清缓存会回到默认

## 说明

只使用浏览器本地存储（`localStorage` / IndexedDB），不上传图片、不联网保存任何数据。兼容 DSH `>=0.2.2-0 <0.3.0`。
